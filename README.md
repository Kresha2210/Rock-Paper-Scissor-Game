# Rock Paper Scissors Game

This project started as a simple Python game in project.py.

It was later converted into a small interactive web game using only HTML, CSS, and JavaScript.

## Live Link: https://rock-paper-scissor-game-kresha.netlify.app/

## Files

- project.py: base version of the game
- index.html: page structure
- styles.css: styling and animation
- script.js: game logic
